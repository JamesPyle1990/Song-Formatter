Song Formatter Bookmarklet

Drag this button to your bookmarks bar:

📋 Send to Song Formatter

How to use

  1. In Song Formatter, type an artist and song, click Search Songs.
  2. A new Ultimate Guitar tab opens. Click a Chords version.
  3. On that chords page, click the Send to Song Formatter bookmarklet.
  4. The lyrics appear back in the app automatically.

If dragging doesn't work, create a new bookmark manually and paste the link's URL as the address.
